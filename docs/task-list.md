## 方針

2026-10-07時点のリポジトリを読み直して作成した。旧タスクリストの再掲ではなく、現行ファイルで根拠を示せる改善を対象とする。番号でブランチを指定し、その中のコミット番号で作業を依頼できる。

- このリストはTODO作成時の調査に基づく。以後の実施状況は各項目のチェックで管理する。
- ブランチ名・コミットメッセージは提案。コミットメッセージは「【概要】説明」に統一する。
- 各コミットに、その変更に必要な日本語の変更記録とTODOの進捗更新を含める。進捗更新だけの独立コミットは原則作らない。

- 未確認を確認済みとして記録しない。既存の手動確認結果と過去の変更履歴は保持する。
- ダークグレー・黄色の配色、作品情報、リンク先、カード列数、軽量な静的構成、既存のGoogle Analyticsを維持する。

## 現状からの判断

- 10件のカードが初期HTMLに存在し、JavaScriptによる生成・データ取得・alert処理はない。
- ゲーム・ツール・メモの説明文、プロフィール、通常一覧の2 / 3 / 4列構成は実装済み。
- canonical、OGP、summary_large_image、1200×630のOGP画像は設定済み。
- h1 → h2 → h3の見出し構造、外部リンクのrel="noopener"、prefers-reduced-motion対応は既にある。これらの全面的な改修を必要とは判断しない。
- カード用画像は最大約48KBであり、容量だけを理由に画像変換・ビルド工程を追加する必要性は低い。
- ブラウザ表示・外部サービスの状態は今回調査していない。以下はローカルファイルから分かる改善候補であり、未確認の表示崩れ・リンク切れを不具合として挙げない。
