# rutile3.com ポートフォリオ改善タスク

ユーザー提供の改善指示書をもとに作成。進捗は以下のチェックリストで管理する。カード静的化の方針は docs/static-project-cards.md に記録済みで、既存10件のカードを初期HTMLに記述済み。不要な生成関数・data.jsonは削除済み。ブラウザでの表示確認は未実施（利用可能なブラウザ接続がなく実行不可。コード確認結果と未確認項目は docs/static-project-cards.md に記録）。
チェックは実装・確認が完了した時点で付ける。任意項目は、見送り理由を記録して管理する。

## 目的・共通制約

「個人リンク集」から「作品を適切に紹介できるポートフォリオ」へ改善する。

- ダークグレーの背景、黄色のアクセント、プロフィール画像、シンプルなカードUI、Bootstrap、ヘッダー・フッター、モバイル対応、現在のURL構造を維持する。
- HTML / CSS / JavaScript中心の軽量構成を維持する。全面リニューアル、React等への移行、不要な依存関係・複雑なビルド構成の追加は行わない。
- 不明な作品情報を創作せず、架空のURL・OGP画像を指定しない。
- Google Analyticsを維持し、大規模なCookie同意管理は追加しない。
- AGENTS.mdに従い、依頼範囲に限定して変更する。コード変更時は追加仕様・仕様変更・バグ修正に応じて、日本語で docs/spec_additions.md、docs/spec_changes.md、docs/bug_fixes.md に記録する。
- 編集後は改行、タブ混入、インデント、不自然なエスケープ文字を確認する。

## 着手時に確認した構成

- index.html、styles.css、app.js、assets/data.json で構成されている。Bootstrap 5.3.3とBootstrap IconsをCDNから読み込む。
- app.jsがJSONを取得してカードを生成するため、初期HTMLの作品一覧は空。取得失敗時は alert() を使用する。
- 登録内容はゲーム4件、ツール4件、メディア2件。ゲーム・ツールの説明は分類中心で、メディアの説明は空。
- 通常カードは row-cols-2 row-cols-sm-3 row-cols-lg-6。代表作品・Aboutセクションはない。
- headにはdescriptionとfaviconがあるが、canonical・OGP・Twitter Cardの設定はない。
- assetsに専用OGP画像は見当たらない。Google Analyticsは導入済み。
- styles.cssにはホバー演出、画像比率の指定、prefers-reduced-motionへの対応がある。
- README.mdはなく、docsは空。link-hub.code-workspaceが存在する。
- CNAMEは rutile3.com。GitHub Pagesの公開元・公開設定は未確認。

## 優先度A：対応

### 3. 代表作品セクション

- [ ] 既存作品から3件程度を選定する。可能ならゲームとWebツールの両方を含める。
- [ ] プロフィールと通常一覧の間に「代表作品」または「Featured Projects」を追加する。
- [ ] 通常カードより大きく、違いが分かり、既存デザインに馴染むカードを実装する。

### 4. プロフィール説明

- [ ] 現在の「プログラマー / ゲームとか作っています」の雰囲気を維持し、掲載内容を伝える短い説明を追加する。
- [ ] 過度な自己PRや根拠のないプロフィール情報を含めない。

### 5. カードサイズ

- [ ] PCの通常一覧を3～4列程度に変更する（例：row-cols-2 row-cols-md-3 row-cols-xl-4）。
- [ ] 実際の表示で長い作品名・説明の折り返しを確認し、PCとモバイルの列数・余白を調整する。

### 6. OGP / SEO

- [ ] canonicalを https://rutile3.com/ に設定する。
- [ ] og:type、og:title、og:description、og:url、twitter:cardを設定し、title・descriptionと整合させる。
- [ ] 使用可能な実在画像がある場合のみog:imageを設定する。
- [ ] 適切なOGP画像がない場合は、画像追加をTODOにし、推奨ファイル名（例：assets/ogp.png）、推奨サイズ（1200×630）、追加後のindex.htmlのog:image設定箇所と公開URLを記載する。画像生成は必須にしない。
