## Tab Link Exporter

### 掲載方針

既存の「ツール」一覧へ掲載する。Chrome拡張機能であることを明示し、一般的なWebツールと区別する。現在のカード構成と配色を維持し、代表作品セクションや新しい分類は追加しない。

### カードの掲載文案

- タイトル：Tab Link Exporter
- 説明：Chromeで開いているタブのタイトルとURLを、一覧として出力できる拡張機能です。
- 種別・仕様の補足：Chrome拡張 / Manifest V3対応

ユーザー提供の説明文を、用途が先に伝わる短い文章に整理した。Manifest V3は用途説明に詰め込まず、種別・仕様の補足として示す。

### 機能・設計・開発上の補足文案

- 出力：URL・Markdown・Cosense・CSV・JSON・カスタム形式に対応。
- 設定：localStorageで設定を保存。
- プライバシー：タブ情報を外部へ送信しない設計。
- 開発・保守：Node.js標準機能による自動テストと、PowerShellによる配布ZIP生成を整備。

これらはユーザー提供の引継ぎ情報を根拠とする。用途説明と補足を分けて掲載し、開発・保守の詳細はリポジトリのREADMEへ案内する。未確認の安全性・ストア審査状況・対応バージョン・テスト結果などは追加しない。
